## 新手从这里开始

- **在手机或电脑上使用**：先找到下面对应的系统，再看工具介绍与支持的配置格式。
- **想让家中设备通过路由器连接**：先确认路由器型号和固件，再查看梅林或 OpenWrt 的插件资料。
- **不清楚客户端、核心和协议的关系**：客户端提供操作界面，核心处理连接，协议约定通信方式；同一种核心可以出现在多个客户端中。
- **已经找到工具，想了解更新**：查看[软件版本与项目动态](UPDATES.md)，点击版本号进入项目发布页面。
