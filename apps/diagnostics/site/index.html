三步开始

  1. 解压下载包，阅读包内中文说明，运行启动脚本。页面只监听本机回环地址。
  2. 选择问题类型，点击开始。默认不测速下载；如勾选下载，每次 HTTP 响应体总量最多 10 MiB、最多 15 秒，每个本地会话最多 20 MiB。
  3. 查看测量结果与可选日志脱敏效果，生成报告预览。点击「提交这份报告」后取得回执，可在本地页面撤回；重启后可恢复最近未完成的提交或回执。

接入 MCP：运行包内「生成 MCP 配置」脚本，把生成的配置加入你的本机 MCP 客户端，再让助手调用 diagnostics_open 打开页面。本版提供打开、状态、报告预览与停止四个工具。

仅支持运行 Node 的桌面环境；不是 iPhone 或 Android 原生应用。远程 MCP 运行在哪里，测到的就是那台机器的网络。

提交前，你能看到什么

完整结构化报告包含时间、平台、问题分类、数值样本、失败码和测试范围。IP、MAC、邮箱、URL、订阅、凭据与本地路径的常见格式会尝试从本地日志预览中遮盖（脱敏仅供辅助）；原始日志与脱敏后的日志全文都不会被提交。

接收端只保存白名单报告，最长 30 天，支持凭删除凭证撤回。报告不会自动公开、不会自动写入评测，也不会送入 GA4。删除凭证保存在你电脑，未撤回前请保留。

网络连接仍会向服务器及 CDN 暴露连接 IP 等传输元数据。本服务不将 IP 写进报告数据库；诊断接口关闭源站访问日志。Cloudflare 的基础网络处理独立于报告字段。

这些数字代表什么

固定目标是本站诊断端点，数据用于定位连接问题。它不是各机场节点的速度排行，也不能代表 YouTube 4K 或其他应用的实际表现。

查看第一版测量边界
  • 使用操作系统直接 socket 连接。TUN 可以影响路由；不会自动读取或使用 HTTP / SOCKS 应用代理。
  • DNS 使用系统配置的 DNS 服务器查询 A / AAAA，不等同于浏览器 DoH、hosts 或完整系统名称解析。
  • TLS 时间包含 TCP 建连；HTTP 时间包含新连接过程。TCP 失败比例不是 ICMP 丢包率。
  • 下载结果是本次固定目标的有限样本，包含连接与传输开销，失败不会伪造速度。10 MiB 限制指响应体，不包括协议开销。
  • 本次发布验收均标记 Linux 实验环境，不能替代真实用户宽带实测。
